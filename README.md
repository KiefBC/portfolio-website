# Portfolio Website

A modern, responsive portfolio website showcasing personal projects, experience, and contact information. Built with SvelteKit, TypeScript, and Tailwind CSS.

## Features

- **Responsive Design**: Optimized for all screen sizes from mobile to desktop
- **Interactive Components**: Animated typing effect, smooth scrolling navigation, and hover animations
- **Interactive Terminal**: Command-line interface simulation for unique user interaction
- **Learning Journey Timeline**: Interactive timeline showcasing technology progression with filterable categories
- **Blog Integration**: Blog section for sharing insights and experiences
- **Project Showcase**: Display of personal projects with technology tags and GitHub links
- **Professional Resume**: Experience, education, and certifications sections
- **Contact Form**: Interactive contact form with status feedback
- **Command Palette**: Quick navigation and search functionality
- **PWA Support**: Progressive Web App capabilities with service worker
- **Modern Styling**: Dark theme with purple accents using Tailwind CSS
- **Accessibility**: ARIA labels and keyboard navigation support
- **SEO Optimized**: Proper meta tags and semantic HTML structure

## Technology Stack

- **Framework**: SvelteKit with TypeScript
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Language**: TypeScript
- **PWA**: Service Worker implementation
- **Animation**: Custom CSS animations and transitions

## Project Structure

- `src/lib/components/` - Reusable Svelte components
  - `Navigation.svelte` - Fixed navigation bar with mobile menu
  - `Hero.svelte` - Landing section with animated typing effect
  - `About.svelte` - About section with skills and interests
  - `Projects.svelte` - Personal projects showcase
  - `Resume.svelte` - Professional experience and education
  - `Contact.svelte` - Contact form and information
  - `CommandPalette.svelte` - Quick navigation and search interface
  - `TechTimeline.svelte` - Interactive learning journey timeline
  - `Blog.svelte` - Blog section component
- `src/lib/data/` - Data files and configurations
- `src/lib/utils/` - Utility functions including PWA support

## Current Projects Featured

- **Swallow AI - Pest Identification System** - Flask-based ML application using ResNet50 for agricultural pest identification
- **Asteroids Game in Rust** - Classic arcade game using Bevy engine with WASD controls and wireframe toggle
- **WWE Universe Manager** - Desktop application built with Tauri 2.0, Leptos, and SQLite for wrestling universe management
- **Acuendo Static Site Generator** - Python-based SSG with Jinja2 templating and Markdown support
- **Python Maze Solver** - Interactive maze generation and solving with Tkinter GUI and depth-first search visualization
- **Rust Shell** - POSIX-compliant shell implementation with builtin commands and REPL interface

This portfolio serves as both a professional showcase and a demonstration of modern web development practices using the SvelteKit framework.
